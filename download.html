📖 Installation Guide

Download the Node

Verify the Checksum

Compare the SHA256 hash to ensure the file is authentic.

3

Windows: Extract the .zip archive and run gtkm.exe.

4

Connect to Network

The wallet will automatically connect to the Tkmchain network. Start mining, managing accounts, or deploying contracts.
